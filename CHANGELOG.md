# Changelog

Notable changes per release. The README's "What's new" sections give the details, including the output
changes to expect when upgrading. Versions follow [Semantic Versioning](https://semver.org); tags have no
`v` prefix.

## [Unreleased]

### Added

- Gradle plugin: every option can be set with a Gradle property named as the Maven plugin's user property
  (`-Paurkitu.validate=false`, or in `gradle.properties`); a value in the build script wins, as in Maven.
- Gradle plugin: several schemas from one project. Any `GenerateFlatBuffersSchema` task the build registers takes
  its options from `aurkitu { }` unless it sets its own, scans the main classes, writes to
  `build/aurkitu/<task name>` and runs with `assemble`.

### Fixed

- An enum with `@FlatBufferEnumTypeField` values, compiled for a newer Java than the one running the build (e.g. a
  Gradle toolchain newer than Gradle's own JVM), was written with implicit values (`0, 1, ...`) instead of its own,
  reported only as a validation comment. The build now fails, naming both Java versions and how to fix it.

### Changed

- Gradle plugin: declares configuration-cache support on the Gradle Plugin Portal.
- Build: the Gradle plugin is built and published with Gradle 9.9; it is tested with 8.14 and 9.9, and with
  Gradle 9.9 on Java 17, 21 and 25. Its unit tests have the same 80% per-class coverage gate as the Maven modules,
  and functional tests cover the build cache (including a relocated checkout) and Kotlin JVM projects.
- Release: the Gradle plugin is built and tested before anything is deployed to Maven Central, and is published
  in its own job. Missing Gradle Plugin Portal keys fail the release instead of skipping the Gradle plugin.

## [1.3.0] - 2026-11-09

### Added

- Gradle plugin `io.github.mhradek.aurkitu`, published to the Gradle Plugin Portal: the `generateFlatBuffersSchema`
  task, with the same options and output as the Maven plugin. Cacheable, and works with the configuration cache.
- `aurkitu-core`: the schema generator as its own artifact, with no dependency on Maven, shared by both plugins.
- README: using the generated schema from other languages (C#, Swift, TypeScript, Go, Rust, ...) with `flatc`.

### Changed

- The Maven plugin's generator classes moved to `aurkitu-core` (same packages); the plugin depends on it. Its
  output and parameters are unchanged. `SchemaGenerator.Config` no longer takes a `MavenProject`.

## [1.2.0] - 2026-11-09

### Changed

- Acronym-aware snake_case is the default (`snakeCaseAcronyms`): `userID` is written `user_id`, not `user_i_d`.
  Field names with consecutive capitals change, so code generated by `flatc` and JSON field names change too;
  binary data does not. Set `snakeCaseAcronyms` to `false` to keep the 1.1 names.

### Added

- `typedMapKeys` (opt-in): map keys keep their Java type (`Map<Integer, V>` gives `key:int`) and are marked
  `(key)`.
- Build: SpotBugs with FindSecBugs fails the build on new findings; reproducible builds; SLSA provenance for
  release artifacts that the release workflow rebuilds byte for byte; a weekly mutation-testing run.
- Repository: `CHANGELOG.md`, `CONTRIBUTING.md`, issue and pull request templates.

## [1.1.1] - 2026-11-09

### Fixed

- Classes of any visibility are scanned. Before, only `public` classes were: fields of a package-private
  superclass were lost, a `private` nested class was written as an empty table, and package-private annotated
  types were not declared.

### Added

- Javadoc for every annotation element, the type enums and every plugin parameter.

## [1.1.0] - 2026-11-07

### Added

- Validation of the FlatBuffers schema rules, matched against `flatc`: invalid parts are reported and left out,
  so the written schema compiles. Warnings for risky but valid schemas.
- `///` documentation comments, optional scalars, `bit_flags` enums, union aliases, RPC services, custom
  attributes, `original_order` and struct `force_align`.

### Fixed

- Maps of maps, repeated `namespace` lines, duplicate field names, enum defaults and optional enum fields.

## [1.0.1] - 2026-11-07

### Fixed

- 1.0.0 scanned the plugin's own classpath and generated empty schemas in real builds.
- Enum underlying types and explicit values, `byte[]` as `[ubyte]`, collection and map detection, nested type
  names, namespace leaks, declaration order, `cacheEnabled` and `flatcPath`.

### Deprecated

- `@FlatBufferOptions`, which never had an effect.

## [1.0.0] - 2026-11-03

- First release under `io.github.mhradek`, migrated from `com.michaelhradek` 0.0.x: Java 17, ClassGraph
  scanning, snake_case field names, validation and an optional `flatc` check.
